Graveyard

Rules

  1. First encounter only. Catch only the first wild Pokémon in each area. If it faints or flees, that area is lost.
  2. Permadeath. A Pokémon that faints is dead. Box it for good and mark it Fainted.
  3. Nicknames. Nickname everything. Lineage Pokémon keep their name in every game.
  4. Dupes clause. If the first encounter is a species line you already own, skip it and take the next new one. Lineage Pokémon count as owned.
  5. Level caps. No Pokémon may be above the current cap when you start that boss fight.
  6. Set mode. Battle style Set wherever the option exists. Violet has no option, so decline the switch prompt there.
  7. Lineage. After each final boss, the surviving party goes to the next game as eggs or base forms at level 5 or below. They are extra to that game's own catches.
  8. Emulator transfers. Recreate survivors in the next save with PKHeX, same species and nickname.
  9. Switch transfers. Get the same species through Pokémon HOME or trades, rename them, and box them until the run starts.
  10. Substitution. If a survivor's species is not in the next game, swap in a Pokémon that shares a type and keep the nickname.
  11. Wipe. If the whole party faints, the Genlocke is over.
  12. End of each leg. A game is cleared when the last boss on its Caps list is beaten. HeartGold runs through Kanto and ends at Red.
